## 1. THE SEED AUDIENCE TEST CYCLE (Why Daily Spamming Kills Channels)
- **Phase-Testing Mechanics**: When a new Short is published, YouTube tests it in discrete seed cohorts:
  - Cohort 1: **100 viewers** (tests Hook Velocity in first 1.5–3 seconds)
  - Cohort 2: **200–500 viewers** (tests Stay-to-Watch Rate > 75% and Average View Duration > 85%)
  - Cohort 3: **1,000–5,000 viewers** (tests Rewatch loops and share/comment engagement)
- **The Self-Sabotage Trap**: If a channel uploads multiple shorts within 12–24 hours, the algorithm aborts the test cohort for the earlier video and redirects distribution resources to the new upload. This traps videos permanently in the **1,000–1,200 view jail**.
- **The Rule**: Allow a Short **at least 24 hours** to complete its test cycle. If it gains 2,000–3,000 views in the first 24h, let it run uninterrupted for **48 hours** before releasing another.

## 3. TRANSFORMATIONAL EDITING VS. SCRAPED RE-UPLOADS
- In 2026, YouTube explicitly de-ranks channels that simply copy/paste clips with minor crops or generic borders.
- **Mandatory Transformation Elements**:
  1. **Kinetic Karaoke Subtitles**: 2–3 words per burst with `#00FFFF` active pop.
  2. **Original Sound Blend**: Subtle, ducked GTA background beats (-18 dB to -24 dB) with active sidechain ducking.
  3. **Visual Pacing**: 1.14x punch-in zoom on emphasis and continuous micro-movement.
  4. **Attribution & Context**: Top banner badge (`STREAM - @STREAMER`), fair use disclaimer, and original angle.

## 4. CRITICAL YOUTUBE CHANNEL SETTINGS
1. **Audience Setting**: Explicitly set to `selfDeclaredMadeForKids=False`. (Marking kids-safe locks comments, disables notification bells, and halts recommendations).
2. **Channel Bio & Storefront**:

   - Channel keywords must include creator names, game titles, and clip genres.
3. **Hashtags**: Exactly **3–5 hashtags** (`#shorts #channel #gaming #viral`). More than 5 triggers the spam penalty.
4. **Community Safety**: Block URL links and generic "sub4sub / support each other" bot phrases in community moderation settings.
